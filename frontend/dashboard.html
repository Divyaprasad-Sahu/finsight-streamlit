The workflow below is implemented in .github/workflows/frontend.yml. This page describes the stages; it does not fetch live GitHub run status.

01 · Docker Compose

The simplest deployment: Streamlit, a metrics exporter, Prometheus, and Grafana on your computer. No cloud account required.

docker compose -f frontend/compose.yml up --build -d

Streamlit :8501 · Prometheus :9090 · Grafana :3000

02 · Local Terraform

The Docker provider manages the Streamlit container using your local Docker daemon. Use this as an alternative to Compose.

cd frontend/terraform
terraform init
terraform plan
terraform apply

03 · Optional Kubernetes

Use a local kind or Minikube cluster. A two-replica Deployment includes Streamlit health probes and a ClusterIP Service.

docker build -t finsight-streamlit:local -f frontend/Dockerfile .
kind load docker-image finsight-streamlit:local
kubectl apply -f frontend/k8s.yaml
kubectl port-forward service/finsight-streamlit 8501:8501

Keep deployment basic

Start with Streamlit directly or Compose. Terraform and Kubernetes are optional ways to demonstrate infrastructure management. AWS and Azure are not used by this frontend deployment.

Monitoring configuration is included. No cluster or monitoring service is queried by this dashboard. Start Docker Compose to see actual exporter metrics in Grafana.

Prometheus

A separate Python exporter fits the demo model and exposes its observed fit duration, sample count, and anomaly count. Prometheus scrapes the exporter every 15 seconds.

finsight_model_fit_seconds
finsight_observations{symbol="AAPL"}
finsight_anomalies{symbol="AAPL"}
finsight_model_last_fit_timestamp_seconds

Grafana

Provisioned Prometheus data source and a dashboard for anomaly counts, input observations, fit duration, and exporter uptime. Metrics describe the exporter’s model run, not uploaded files or Streamlit sessions.

http://localhost:3000
User: admin
Password: set GRAFANA_ADMIN_PASSWORD
in frontend/.env before starting Compose
Built on the FinSight AI repository. This lightweight Streamlit implementation is independent of the original Kafka/Spark/LLM stack and runs without API keys.
Run in three steps
python -m venv .venv
# Windows: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r frontend/requirements.txt
streamlit run frontend/app.py
What is running?
The Streamlit process trains the scikit-learn demo models in Python and embeds this interface with the resulting data. Charts, filters, model reports, and CSV exports work locally in your browser.
The original repository’s full serving dashboard remains at serving/dashboard/streamlit_app.py.
